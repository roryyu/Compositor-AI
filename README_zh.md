# Compositor-AI

> 简体中文版，与 [README.md](README.md) 同步维护。

Adobe Photoshop 太贵，而 GIMP 这类工具又不够顺手，很难让我保持专注。这就是我写 Compositor 的原因。

目标是一款功能完整、完全免费且开源的图像编辑器。我平时用 Photoshop 做合成与后期，所以 Compositor 就是围绕这套工作流构建的——拥有产出像素级完美成品所需的全部工具。

因为开源，你可以下载 Xcode 工程，按自己的工作流增加、删除或修改任何功能。

> **本项目是 [robbietilton/Compositor](https://github.com/robbietilton/Compositor) 的 fork。** 完整保留了原版编辑器，并增加了一层内置 AI 能力：可配置的 AI 服务商、直接在画布里生成的文生图，以及一个替你操作文档的 AI 智能体。详见下文 [AI](#ai) 一节。

## 功能

### 图层
- 图层与图层组，支持不透明度和 Photoshop 全套混合模式（按 Photoshop 的排序）——图层组的不透明度会整体压暗组内所有内容
- 图层蒙版：可绘制、填充、反相、模糊和羽化；可链接/取消链接，单独变换蒙版本身
- 剪贴蒙版与图层组蒙版
- 调整图层：色相/饱和度、色阶、曲线、曝光、渐变映射、颗粒、黑白、色彩平衡、自然饱和度、通道混合器、颜色查找、照片滤镜、阴影/高光、去饱和度、色调分离、阈值、反相、高斯模糊、动感模糊和噪点
- 图层效果：描边、投影、颜色叠加、内阴影、外发光和内发光，全部在 GPU 上渲染，随时可编辑
- 向下合并、合并图层与合并组（⌘E）
- 拷贝、就地重命名、拖拽排序与嵌套；Option 拖拽即拷贝；图层面板自带右键菜单
- 整层与图层组的复制粘贴（无选区时 ⌘C/⌘V），可在同一文档内或跨文档进行，也可以直接拖到另一个文档

### 变换
- 非破坏性的移动、缩放、旋转与翻转——无论把图像缩得多小，都保留完整分辨率
- 自由扭曲（⌘ 拖拽控制点），按住 Shift 可锁定到轴向
- 多个图层或整个图层组一起变换
- 吸附到画布与图层的边缘、中线，配合参考线使用
- 位置、大小、缩放与角度可输入精确数值，方向键按步长微调
- 翻转图层与翻转画布，水平、垂直皆可

### 选区
- 矩形/椭圆选框、自由套索、多边形套索，以及魔棒家族——魔棒按颜色选取，对象选择自动勾勒点击的目标（Tab 键切换）
- 选取主体；任意选区都可扩展、收缩、羽化
- 加选、减选、移动选区边框，或移动/拷贝选区内的像素
- 把图层的像素或蒙版载入选区
- 内容识别填充，还能把图像向画布边缘之外扩展

### 绘制与修饰
- 画笔：大小、硬度、不透明度、平滑；画笔与擦除模式（B 和 E），Shift 画直线
- 污点修复画笔（内容感知）
- 仿制图章：对齐或不对齐，按单层或全部图层取样
- 模糊工具：可用于像素或蒙版；涂抹（模糊/液化/混色）——混色即混合器画笔，载入前景色并在划过时与下方像素混色
- 减淡、加深与海绵工具，可选阴影/中间调/高光范围，在涂抹处提亮、压暗或调整饱和度
- 渐变工具、形状工具（矩形、圆角矩形、椭圆、直线）与钢笔工具（用贝塞尔控制点填充或描边路径），保持可编辑而不被栅格化；路径还可转为选区或栅格化为普通像素
- 文字工具（T）：可拖拽、可调整大小的段落框内直接多行编辑；工具头提供字体、字号、颜色、对齐与间距；文字可变换，也可用作剪贴蒙版
- 吸管与完整的颜色选取器

### 调整与滤镜
- Camera Raw 滤镜：光影、颜色、曲线、色彩混合器、色彩分级、细节、光学与几何，在画布旁的独立面板中完成
- 色阶（含自动）、曲线、色相/饱和度、曝光、渐变映射、颗粒、黑白、色彩平衡、自然饱和度、通道混合器、颜色查找（`.cube` 三维 LUT）、照片滤镜、阴影/高光、去饱和度、色调分离、阈值与反相
- 高斯模糊与动感模糊，效果可以溢出图层边缘
- 锐化、USM 锐化、方框模糊、镜头模糊、移轴模糊与放射状模糊
- 马赛克、晶格化、点刻化；旋转扭曲、波浪变形与置换变形（置换以另一个图层作为置换图推动像素）
- 添加噪点、暗角、辉光、色调对比、镜头校正与移除背景
- 实时预览；有选区时自动限定在选区内

### 画布与文件
- 多文档标签页
- 标尺（⌘R）、从标尺拖出参考线、版式网格，以及吸附到参考线、网格、图层与文档边界
- 带吸附的裁剪，内置 3:4、9:16 等比例，Option 对称裁剪；有选区时裁剪框从选区开始
- 画布大小、图像大小与裁除
- 缩小查看时高质量锐利降采样，放大查看时显示像素网格
- 导入 JPEG、PNG、HEIC、TIFF、SVG、相机 RAW（先走显影步骤）以及 Photoshop PSD 与 PSB（8 位 RGB；不支持 CMYK）。Photoshop 的图层组、蒙版、混合模式、填充矩形/椭圆与简单横排文字保持可编辑；其他矢量与竖排文字转为像素。应用之前会先展示转换报告。
- 大文档：内存预算随你的 Mac 伸缩；打不开的超大 Photoshop 文件会把图层裁切到画布大小后再载入
- 导出 JPEG 带实时预览（⇧⌥⌘S）；合并拷贝
- 全局 Photoshop 风格快捷键，可在 编辑 > 键盘快捷键 中重新映射
- 自动更新，已签名并公证

### AI
所有 AI 功能都在 **AI** 菜单下（AI 设置…、生成图像… ⇧⌘G、分析画布…、AI 编辑…）。
- 自带密钥：兼容任何 OpenAI 格式的多模态端点，内置 OpenAI、阿里云百炼（DashScope）、火山方舟、智谱、Gemini、Ollama 等预设
- 视觉/对话与图像生成分开配置——各自独立的 base URL、API Key 与模型；API Key 存放在系统钥匙串，「测试连接」按钮逐一验证每套配置
- 文生图（⇧⌘G）：描述你要的内容，结果自动缩放至画布并作为新图层插入；支持 OpenAI Images、火山 Seedream、DashScope 万相与 Gemini
- 分析画布：向视觉模型提问当前文档
- AI 编辑：智能体通过 function calling 直接操作编辑器——建图层、绘制、填充、选区（可扩展/收缩/羽化）、变换、添加与反相图层蒙版、施加图层效果、内容识别填充，以及带参数的全部滤镜与调整——每一步都展示在面板里。每个动作都是普通的撤销步骤，⌘Z 即可回退

### 外部控制（MCP）
App 内置一个仅本机可达的控制 API（127.0.0.1、临时端口、每次启动颁发令牌），`Tools/CompositorMCP` 是一个零依赖的小型桥接，说 [MCP](https://modelcontextprotocol.io) 协议，让 OpenAI Codex（或 ChatGPT、Claude 等）外部智能体用与 App 内智能体相同的工具集操作当前文档。若 Compositor 未运行，桥接会自动启动它。

构建桥接：

```sh
cd Tools/CompositorMCP && swift build -c release
```

在 `~/.codex/config.toml` 中向 Codex 注册：

```toml
[mcp_servers.compositor]
command = "/absolute/path/to/Tools/CompositorMCP/.build/release/compositor-mcp"
```

#### 安装智能体技能（推荐）

`Tools/CompositorMCP/SKILL.md` 是面向智能体的使用指南：何时触发、先看状态再动手的工作流、工具约定（短图层 id、左上角为原点的文档坐标、颜色格式）与常用配方。装上它，Codex 才知道怎么把 Compositor 用好：

```sh
mkdir -p ~/.codex/skills/compositor
cp Tools/CompositorMCP/SKILL.md ~/.codex/skills/compositor/SKILL.md
```

然后重启 Codex。MCP 服务器提供工具，技能告诉智能体怎么用、何时用——两者齐备，「在 Compositor 里画一个 50 像素的黑色圆」这类指令才能稳定生效。

无需任何配置也可以直接从 shell 使用：`compositor-mcp health | tools | state | call <tool> '[json arguments]'`。

## 环境要求

- macOS 26.5 或更高
- Xcode 26 或更高（从源码构建时）

## 构建

打开 `Compositor.xcodeproj`，运行 **Compositor** scheme。

## 发布

`scripts/release.sh` 会构建 Release 版本，用 Developer ID 签名、公证并装订，最终打包为 `dist/Compositor-<version>.dmg`。

以下凭据全部保存在本仓库之外：

- 登录钥匙串中的 **Developer ID Application** 证书
- 用 `xcrun notarytool store-credentials "compositor-notary" …` 保存的公证凭据
- [`create-dmg`](https://github.com/create-dmg/create-dmg)（`brew install create-dmg`）
